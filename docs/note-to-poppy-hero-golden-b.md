**สรุปหัวข้อเดียว:** numeric gate (G3/G5/G6) ผ่านแล้ว + แกน **identity ผ่าน — ห้ามแตะ** (แดดหน้าต่างซ้าย · bounce อุ่น · teal accent เข้าเป้า). ที่เหลือคือชั้น "เสน่ห์" ที่ตัวเลขจับไม่ได้ เรียง P0 → P2. เกรดเฉพาะพาส #3/#5/#7/#9 + composition.

**ลำดับลงมือ:** palette + composition → DOF + god-ray → PBR. **ลด saturation เป็นอย่างแรกเสมอ** — ส้มจัดคือตัวทำลาย mood มากที่สุด แก้ทีเดียวยกทั้งเฟรม.

## P0 — ปิดเสน่ห์ที่คนเห็นทันที (แก้ก่อน)

### #9 Palette — ส้มจัด/แข็ง → ต้องเป็น honey-amber นุ่ม
- **เห็นใน b:** ทั้งเฟรมส้มอิ่มจัด สีแบนเป็นบล็อกพลาสติก/ของเล่น ไม่ใช่ครัวอุ่น. เส้นเงาตัดคม.
- **ref เป็น:** honey-amber ทุ้มต่ำ นวลแบบ cinematic โทนเดียวกันแต่ desaturate.
- **สั่ง:** ลด saturation ~15–20% ทั้งเฟรม · ยก **shadow floor เป็นน้ำตาลอุ่น — ห้ามดำสนิท** (จุดมืดสุด eyedrop แล้วต้องยังเห็นเนื้อไม้ + โทนอุ่น ไม่ใช่ดำ ไม่ใช่ฟ้า) · กัน highlight clip ตรงชาม/ผนังฝั่งแดด.
- **เช็คตรงไหน:** floor checker ใน b มืดเกือบดำ → นั่นคือ shadow floor ที่ต้องยก.

### composition — ชาม hero อ่านเป็นบล็อกเคาน์เตอร์ → ต้องเป็นชามเซรามิก
- **เห็นใน b:** ชามใหญ่/เหลี่ยม ลอยอยู่บนก้อนน้ำตาล อ่านเป็น "เคาน์เตอร์ยักษ์" มากกว่าภาชนะ. มี inner cavity แล้วแต่สัดส่วนบวม.
- **ref เป็น:** ชามเซรามิก sil ชัด — มี **rim (ขอบปากลิป)** โค้งรับแสง · **inner cavity** · **ตีนชาม (foot) สอบเข้า** วางบนไม้ plank.
- **สั่ง:** ย่อ scale ชามลง · เพิ่ม rim lip ให้ขอบปากอ่านออก · ทำ foot สอบเข้าให้ตั้งบนไม้จริง (ไม่ใช่วางบนบล็อกลอย). เป้า = silhouette ต้องบอกได้ว่า "ชาม" ตั้งแต่แวบแรก.

## P1 — ยกจาก "ผ่าน" เป็น "สวย" (ตัวแยกเกม→โฆษณา)

### #5 DOF — คมทั้งภาพ → fg ชามคม / bg ละลาย bokeh
- **เห็นใน b:** ทุกอย่างคมเท่ากัน — ตู้เย็น · ผนัง checker · floor ชัดหมด ไม่มีระยะ.
- **ref เป็น:** ชาม fg คมกริบ / ตู้-ชั้น-ผนัง bg ละลายเป็น bokeh นุ่ม → ตาวิ่งไปที่ชามทันที.
- **สั่ง:** วาง focal plane ที่ชาม hero, ดัน bg ให้ฟุ้ง. คุ้ม effort สุดในกลุ่ม P1 เพราะเป็นตัวทำให้ "ดูเป็นโฆษณา" ไม่ใช่ screenshot เกม.

### #3 God-ray — ลิ่มแข็ง → แท่งนุ่มตาม mullion + dust motes
- **เห็นใน b:** ลำแสงเป็น **สามเหลี่ยมคมตัด (hard wedge)** พาดทแยง ขอบมีดโกน ไม่มีฝุ่น ไม่มีลาย mullion.
- **ref เป็น:** แท่งแสง volumetric นุ่ม ขอบฟุ้ง · **sample เงาแกน mullion** ของหน้าต่างเป็นแถบอ่อน ๆ · มี **dust motes** ลอยในลำแสง.
- **สั่ง:** ทำขอบลำแสงให้ soft (ไม่ใช่รูปทรงคม) · ให้แถบเงา mullion โผล่ในลำแสง · เติม dust motes ลอย.

## P2 — เก็บรายละเอียด PBR

### #7 PBR — ตู้เย็นขวาแบนด้าน → stainless specular streak
- **เห็นใน b:** ตู้เย็นฝั่งขวาเป็นแผ่นเทา/ขาวด้าน แบน ไม่สะท้อน.
- **ref เป็น:** ผิว stainless มี **vertical specular streak** (แถบสะท้อนแนวตั้งไล่โทน) รับแสงหน้าต่าง อ่านเป็นโลหะขัด.
- **สั่ง:** ใส่ vertical specular gradient/streak บนหน้าตู้เย็นให้จับแสงหน้าต่างซ้าย.
