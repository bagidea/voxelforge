## เป้าหมายแรกที่เล็กที่สุด — **"The Gatekeeper"** (3 นาที)

**0:00** เข้าใกล้กองไฟ → ไฟลุกแรง + ข้อความ 4 วิ *"ประตูทางเหนือ ยังมีบางอย่างเฝ้าอยู่"* → **0:20** เดินตามถนนขึ้นเหนือผ่านบ่อน้ำ → **1:00** Guard Husk 1 ตัวที่ ~(32,12) เห็นก่อนไกลๆ + HUD เลือด/สตามินาโผล่ → **สู้ ตายได้ → เกิดที่กองไฟ → husk รีเซ็ต → กลับมาใหม่** (ช่วงที่ผู้เล่น*เรียนรู้*) → **2:30** ชนะ → sigil เรืองแสง + ประตูเปิด 3 บล็อก → **3:00** เดินเข้าซุ้ม = จบเดโม.
**ครบวง:** เป้า → อุปสรรค → ล้มเหลวที่ไม่ลงโทษ → ชัยชนะ → **โลกเปลี่ยนเพราะผู้เล่น**. **ของใหม่ 4 ชิ้น:** husk spawn บนแมพที่โหลด · trigger รอบกองไฟ · objective 1 บรรทัด · on-death → เจาะประตู+สลับ sigil.
**ชั่งแล้วไม่เลือก:** "เก็บของ 3 ชิ้น" (ต้องสร้าง pickup+inventory ใหม่ ไม่มีความเสี่ยง) · "จุดคบไฟ 3 จุด" (ไม่มีศัตรู = ยังไม่ใช่ action) — แพงกว่าและได้ความรู้สึกเป็นเกมน้อยกว่า เพราะ combat ที่เสร็จแล้วยังนอนอยู่เฉยๆ.
