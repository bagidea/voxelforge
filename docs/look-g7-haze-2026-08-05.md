# G7 — aerial-perspective haze default (2026-08-05, flamingo)

Handoff record for the change committed in `client/src/look.rs`. Standalone copy:
`docs/patches/flamingo-g7-haze-default.patch`. The sweep lane (`_flamingo_g7/`) and its
analysis scripts (`scripts/_flamingo_g7_*.py`) are gitignored, so this file is the durable
part; `scripts/grade_g7.py` — the gate everything below is measured against — is committed.

## What shipped

| constant | value | why |
|---|---|---|
| `HAZE_DENSITY` | `0.0072` | `FogFalloff::ExponentialSquared`. Quadratically flat near the camera (0.5 % @ 10 blocks, 8 % @ 40, 99.5 % @ 320). Floor is `0.00673` — the streaming contract (`RENDER_RADIUS` 320); below it a popping chunk shows through. |
| `HAZE_DESAT` | `0.40` | Horizon is not the zenith: push the sky hue toward white. |
| `HAZE_GAIN` | `0.62` | Priced as a fraction of `Hour::sky_gain`, so the haze cannot drift off the sky it is derived from. Under 1.0 or the horizon band comes out brighter than the sky and silhouettes in reverse. |

`FOG_START 112` is kept as the legacy linear curve and is what `VOXELFORGE_LOOK_HAZE=0`
selects — that is how the before/after pair is shot from **one** binary.

The same commit hoists SSAO out of the per-tier `match` (present at every tier; High steps
8 spp → 18 spp) and adds the sweep hooks `VOXELFORGE_LOOK_HAZE / HAZECOL / HAZEDESAT / SSAO /
SSAOQ / PCSS`. Unset ⇒ the tier's own values, byte for byte.

Build that produced the numbers below: `--profile perf`, `Finished in 24m 56s`, `EXIT=0`,
`grep -c '^error' build.log` = 0, exe 99,521,024 B @ 02:28:24. 16/16 sweep rows, camera pinned
`VOXELFORGE_LOOK_CAM=35,-18,26` on every row.

## What it costs — stated, not skipped

The win is real and it is **not free**. Both halves belong in the record.

**Buys** (vs `VOXELFORGE_LOOK_HAZE=0`, i.e. the G6 frame):

* vegetation saturation 79.7 → 60.3 %, clearing `T_VEG_SAT <= 62.8` — the only lever in the
  sweep besides a global post-grade that clears it at all.
* interior floor G3 p05 17.5 → 24.1.
* G3 / G5 / G6 all still PASS; sky pixels unchanged (44.2 → 44.1 sat, 0.0 deg).

**Costs**:

* stone (terracotta) saturation −39.3 % far / −35.1 % mid / −22.4 % near, hue +16.5 / +22.5 /
  +11.3 deg. Visible: the roofs read pink-grey. Depth-graded, so partly the intended aerial
  perspective — but the near-field share of it is the A2 bug below, not intent.
* micro-contrast 6.34 → 5.47 (−13.7 %). Still 0.47 over the `>= 5.0` gate
  (`grade_axes.py:50`).
* vegetation **hue** 89.1 → 96.9 — 7.8 deg the *wrong* way. Axis C has two halves; haze fixes
  saturation and worsens hue.

⚠️ Method note for whoever measures the next lever: the sky mask **cannot** show a distance-fog
cost — no geometry behind those pixels. A "0.1 sat on the sky" result is not evidence of
freeness. Measure the material regions (`scripts/_flamingo_g7_stone.py`).

## Not shipped, and why

* **No `VOXELFORGE_LOOK_GRADE` row as a default.** `g07s65` is the only row that PASSES axis C
  outright — and it does it by desaturating the **sky** 44.1 → 18.9 (−57 %), dragging its hue
  +24 deg into violet and its value −13 %. Axis C masks to hue 40..150 (`grade_g7.py:88-98`),
  so the gate is structurally blind to that. The gate passing is not the frame being better.
* The remaining vegetation distance is **albedo** — `BlockId::base_color` in `voxel.rs`,
  shiba's lane, exactly as `grade_g7.py:50-55` scoped before the sweep ran. A global
  desaturate is not a substitute for it.

## Next one-line change (measured, not yet baked)

`HAZE_DESAT` **0.40 → 0.60** (sweep row `hd60`) improves on the shipped default on every axis
measured except one: p05 25.0 vs 24.1 · veg hue 93.3 vs 96.9 · veg sat 61.7 vs 60.3 (both
pass) · stone hue drift cut ~6 deg (near band 28.6 vs 38.9 — terracotta keeps its colour) ·
sky and p95 identical · G3/G5/G6 P P P. Cost: micro-contrast 5.41 vs 5.47 (−1.1 %).

It is an **env-override result**. Before it ships it must be re-shot with the constant compiled
in and proven to reproduce out-of-box — an env crutch is not a default.

## Open bugs (look lane)

1. **A2 — near-field haze floor.** Depth ratio must be `>= 2.5` (`grade_g7.py:63`).
   Whole-frame row bands give **0.97**, but that top band contains sky, which does not move
   under fog and so dilutes the far number — conservative, not inflated. Re-measured with the
   same metric (`grade_g7.py:160-166`) on a **sky-free stone mask**: far 35.75 / mid 27.91 /
   near 19.52 → **1.83**. So the haze IS depth-dependent (monotonic across three bands), just
   not steep enough. The defect is the near-field floor: 19.5 of movement on ground a few
   blocks from the camera, where `ExponentialSquared` @ 0.0072 predicts < 2 % opacity.
   Something adds a near-field term the density curve does not account for.
2. **B — SSAO is not biting.** `VOXELFORGE_LOOK_SSAO=off` vs on: p99 darkening **1.40**
   (need `>= 10.0`), coverage **0.44 %** (need `>= 2.0`). The layer is in the frame and the
   frame barely changes. Not reachable by tuning; needs its own look.
