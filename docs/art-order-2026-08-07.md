## อันดับ 2 · ไม่มีจุดสนใจเดียว + ไฮไลต์แตกเป็น 5 เกาะ + vignette กลับด้าน — Shiba

**เรา:** กล่องน้ำตาลขนาดเท่ากัน 30+ ก้อน ค่าสว่าง/ความคม/ขนาดเท่ากันหมด — ไม่มีพระเอก

## อันดับ 3 · ไม่มี atmospheric perspective เลย — ฉากแบนเป็นแผ่นเดียว — Shiba (+ Rose = ตัว fog shader)
วัดแล้ว **near−far saturation ต่างกันไม่ถึง 1 percentage point ทั้งสามเฟรม** (ทุกแบนด์อยู่ 84–93%)
ระยะ 2 บล็อกกับ 40 บล็อกใช้สีอิ่มเท่ากัน

| | near−far sat | near/far localRMS | near/far ink ratio | lum overlap near/far |
|---|---|---|---|---|
| **golden ref** | +0.9pp | **+105.3%** | **44.15×** | 68.6% |
| boot | −1.0pp | **−52.8% (กลับด้าน)** | 0.23× | **78.9%** |
| walk | +0.9pp | −5.3% | 1.09× | 74.6% |
| combat | +0.3pp | +16.8% | 0.88× | 54.9% |

ref เองก็ saturation สูงทุกแบนด์ (94.9/92.5/95.8) แต่ **ชดเชยด้วย micro-contrast** — near สูงกว่า far เท่าตัว
(1.78 → 3.65). ของเรา boot กลับด้านสนิท (ฉากไกล "ยุ่ง" กว่าฉากใกล้ 5.79 vs 2.73)

นอกจากนี้ **จุดถ่ายปัจจุบันมีผนังบังที่ 3–8 m** จึงไม่มีระยะให้ haze ทำงานตั้งแต่แรก และ DOF ในเฟรม walk
ไปเบลอ "ผนังที่บังกล้อง" ทางซ้าย ~35% ของเฟรม = ดูเหมือนกล้องติดของ ไม่ใช่ความลึก

**ต้องทำ**
- height/distance fog ที่ทั้งลด saturation และดึงค่าเข้าหาสีฟ้าท้องฟ้า
- เลือก/สร้างจุดถ่ายที่มี **แนวสายตาทะลุ 20 m+** (ทางเดินยาว / ระเบียงมองลงหมู่บ้าน)
- วาง **foreground occluder ตั้งใจ** ที่ ~1–2 บล็อกหน้ากล้อง (ซุ้ม/กิ่งไม้/ผ้าใบ/ขอบโต๊ะ) **มืดกว่าฉากกลาง ≥25 L**
  — เสาเบลอซ้ายมือใน walk คือชั้นที่อ่านง่ายที่สุดในทั้งสามภาพ และมันเกิดโดยบังเอิญ ทำให้เป็นระบบ

**เกณฑ์รับ (แก้แล้ว):** **near/far localRMS ≥ +60%**

| | near/far localRMS | ผ่าน? |
|---|---|---|
| **golden ref** | **+105.3%** | ✅ |
| boot | −52.8% | ❌ |
| walk | −5.3% | ❌ |
| combat | +16.8% | ❌ |

⚠️ ~~far-band sat ต่ำกว่า near 15–25pp / ต่ำกว่า 15pp อย่าส่ง~~ **ตัดออกจากประตูส่งงาน** — **ref เองวัดได้ +0.9pp**
(near อิ่มกว่า far) เท่ากับเราเป๊ะ เมตริกนี้ **แยก ref ออกจากเราไม่ได้เลย** จะตั้งเป็น hard gate ไม่ได้
สิ่งที่ ref ชนะคือ micro-contrast ไม่ใช่ desaturation — ตามตารางด้านบนที่เอกสารนี้เขียนไว้เองแล้ว

> เป้า far-band sat จะกลับมาเป็นเกณฑ์ได้ **เฉพาะเมื่อมีจุดถ่าย vista ระยะ 20 m+** (ซึ่งยังไม่มี — เป็นงานในข้อนี้เอง)
> ฉากปัจจุบันมีผนังบังที่ 3–8 m ระยะไม่พอให้ haze ทำงาน จึงวัด atmospheric perspective ด้วย sat ไม่ได้ตั้งแต่ต้น
> **ลำดับคือ: ทำจุดถ่ายทะลุ 20 m+ ก่อน → แล้วค่อยตั้งเลข sat จากภาพจริง ไม่ใช่เดาล่วงหน้า**

**ต้องทำ (เปลี่ยนจาก implement → A/B):**

4. ทั้งสองกรณี: commit ของที่ค้างอยู่ พร้อมภาพ A/B แนบ — ตอนนี้มันยัง uncommitted
